# 🌱 The Last Seed

> An immersive 3D storytelling experience about hope, rebirth, and the future of our planet.

## 🌍 Live Demo

https://the-last-seed-3d.netlify.app

## 📖 Overview

**The Last Seed** is an interactive 3D storytelling website that takes visitors on an emotional journey through the collapse and rebirth of nature.

The experience begins with the last surviving seed on Earth. As users scroll through the story, they witness a dying world, the return of rain, the growth of a new forest, and finally, a new beginning. The project combines storytelling, animation, and 3D graphics to create an engaging and memorable web experience.

## ✨ Features

- 🌱 Interactive 3D seed built with Three.js
- 🌌 Animated star field
- 🌧️ Rain animation
- 🍃 Growing leaves animation
- 📜 Scroll-based storytelling
- 📊 Scroll progress indicator
- 🔄 Restart experience button
- 📱 Responsive design
